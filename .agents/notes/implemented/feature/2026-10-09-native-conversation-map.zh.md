# Agent Note: 原生对话地图

Status: implemented

[English](2026-10-09-native-conversation-map.md) | 中文

## Problem

一个有用的回答可能引出几条独立的探索。平面的会话列表会丢失它们的来源，临时侧边对话则会丢失有用的工作。用空间方向命名分支操作，还要求用户在表达下一个问题前先选择布局方向。

## Decision

可选的 [Session Tree Host](../../../../packages/experimental/session-tree/README.zh.md) 和[地图界面](../../../../packages/experimental/client-ui-session-tree/README.zh.md) 将原生 Session 的父子关系展示为按需打开的地图。打开卡片会返回同一个原生对话。原生聊天负责从回复处分支并保留精确的已提交前缀，方向由自动布局决定。

对话名称仍由原生 Session 标题持有，从卡片编辑的名称也是如此。地图负责摘要注解、展示状态与成果预览。当前原生会话决定高亮的祖先路径。原生 Pin、工作区导航、审批、工具和交付文件仍由各自的插件负责。独立分支共用原工作区；对话关系不会为文件拍摄快照，也不会复制供应商的 KV 张量。

初始视图聚焦当前相连的探索。搜索结合卡片文字与当前原生消息正文，并包含隐藏的对话。地图读取公开的 Session 观察结果，复用语义文本辅助函数完成字面匹配，使中文片段和记住的短词无需扩展原生搜索 API 或启用索引就能匹配。搜索只保留当前请求的摘录，不创建另一份消息存储。选择结果会恢复可读比例；缩小后的总览保留清楚的名称，隐藏次要细节。展开和折叠只减少可见细节，不移除已保存会话。预览优先使用声明的文件，并区分文本引用与已经验证的外部成果。

[插件包](../../../../packages/experimental/session-tree-bundle/README.zh.md) 为 Host 与界面提供统一的安装和启停入口。它只插入这两个组件，不覆盖内置配置。搜索使用公开的观察 API，因此安装无须修改原生查询或控制器包。运行时关闭会移除两个组件，同时保留原生会话与持久化注解，供重新启用时读取。

## Alternatives considered

**分别提供向下续接和向右分支。** 两个操作都创建会话，但方向暗示了不同的语义关系。普通续接现在留在原有聊天中，原生分支仍是明确的新建操作。

**以地图作为主要编辑界面，或保持永久分屏。** 两者都让空间导航成为普通对话的前置条件，并与现有输入框和工具争夺空间。按需打开地图保留了熟悉的写作界面。[Sensecape](https://sanghosuh.github.io/papers/sensecape_uist.pdf) 和 [Graphologue](https://jiang.pl/papers/graphologue.pdf) 支持用空间视图探索，同时也报告了导航或表示成本；这些小规模、特定任务研究不能证明存在普遍更好的编程界面。

**另存主线标记，并在地图中维护一份聊天记录。** 这些能力重复了当前会话导航和原生对话展示。派生的路径跟随实际工作，原生 Pin 提供持久快捷入口。返回所属对话可以保留已有扩展，避免出现第二套工具或审批界面。

## Consequences

递归关系和注解可跨重启保存，无须第二套会话生命周期。插件不添加模型提示。精确的继承前缀允许供应商按正常机制复用缓存，但不保证命中缓存。

地图没有常驻总览和直接编辑产物的能力。交付文件引用会返回其所属对话。首次加载读取普通会话日志；后续仅在实时实例和游标，或持久化实例和修订仍有效时复用投影。卡片自动布局，尚未实现虚拟化。

## Testing

Host 组合测试覆盖原生递归分支、前缀保留、注解持久化、日志修订变化、持久化实例替换、取消与卸载。界面测试覆盖原生导航、展开折叠、搜索，以及注解保存失败后保留未保存编辑。完整 Web 回归检索不在卡片标题和摘要中的中文片段、单字与不区分大小写的英文正文。无密钥脚本示例提供了可复现的完整体验，无须供应商凭据。
